# Hello, World!

در اینجا برنامه‌ای ساده آورده شده است که `"Hello, world!"` را چاپ می‌کند:

```kotlin
fun main() {
    println("Hello, world!")
    // Hello, world!
}
```

در Kotlin:

* از `fun` برای اعلان یک تابع استفاده می‌شود.
* تابع `main()` نقطهٔ آغاز اجرای برنامهٔ شما است.
* بدنهٔ تابع میان آکولادهای `{}` نوشته می‌شود.
* تابع‌های [`println()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.io/println.html) و [`print()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.io/print.html) آرگومان‌های خود را در خروجی استاندارد چاپ می‌کنند.

تابع مجموعه‌ای از دستورها است که کاری مشخص را انجام می‌دهد. وقتی تابعی بسازید، هر زمان که لازم باشد آن کار انجام شود، می‌توانید از آن استفاده کنید؛ بدون آنکه لازم باشد دستورها را دوباره بنویسید. تابع‌ها چند فصل بعد با جزئیات بیشتری بررسی می‌شوند. تا آن زمان، همهٔ مثال‌ها از تابع `main()` استفاده می‌کنند.

## متغیرها

همهٔ برنامه‌ها باید بتوانند داده ذخیره کنند و متغیرها این کار را ممکن می‌کنند. در Kotlin می‌توانید اعلان کنید:

* متغیرهای فقط‌خواندنی (read-only) با `val`
* متغیرهای تغییرپذیر (mutable) با `var`

> [!note]
> پس از مقداردهی به یک متغیر فقط‌خواندنی، نمی‌توانید مقدار آن را تغییر دهید.

برای انتساب مقدار، از عملگر انتساب `=` استفاده کنید.

برای نمونه:

```kotlin
fun main() {
//sampleStart
    val popcorn = 5    // There are 5 boxes of popcorn
    val hotdog = 7     // There are 7 hotdogs
    var customers = 10 // There are 10 customers in the queue

    // Some customers leave the queue
    customers = 8
    println(customers)
    // 8
//sampleEnd
}
```

> [!tip]
> می‌توانید متغیرها را در ابتدای برنامه و بیرون از تابع `main()` اعلان کنید. به متغیرهایی که به این شیوه اعلان می‌شوند، **سطح بالا (top level)** گفته می‌شود.

از آنجا که `customers` متغیری تغییرپذیر است، می‌توان پس از اعلان مقدارش را دوباره انتساب داد.

> [!note]
> پیشنهاد می‌کنیم همهٔ متغیرها را به‌طور پیش‌فرض فقط‌خواندنی (`val`) اعلان کنید. فقط هنگامی از متغیرهای تغییرپذیر (`var`) استفاده کنید که واقعاً به آن نیاز دارید. با این کار احتمال تغییر تصادفی چیزی که قرار نبوده تغییر کند، کمتر می‌شود.

## قالب‌های رشته‌ای

دانستن چگونگی چاپ محتوای متغیرها در خروجی استاندارد مفید است. می‌توانید این کار را با **قالب‌های رشته‌ای (string templates)** انجام دهید. می‌توانید از عبارت‌های قالب (template expressions) برای دسترسی به داده‌های ذخیره‌شده در متغیرها و دیگر شیءها و تبدیل آن‌ها به رشته استفاده کنید.
مقدار رشته‌ای دنباله‌ای از نویسه‌ها درون علامت نقل‌قول دوتایی `"` است. عبارت‌های قالب همیشه با علامت دلار `$` شروع می‌شوند.

برای ارزیابی قطعه‌ای کد در یک عبارت قالب، کد را پس از علامت دلار `$` میان آکولادهای `{}` قرار دهید.

برای نمونه:

```kotlin
fun main() {
//sampleStart
    val customers = 10
    println("There are $customers customers")
    // There are 10 customers

    println("There are ${customers + 1} customers")
    // There are 11 customers
//sampleEnd
}
```

برای اطلاعات بیشتر، [قالب‌های رشته‌ای](../strings-fa.md#الگوهای-رشته‌ای-string-templates) را ببینید.

متوجه می‌شوید که برای متغیرها هیچ نوعی اعلان نشده است. Kotlin خودش نوع را استنتاج کرده است: `Int`. این تور، نوع‌های پایهٔ مختلف Kotlin و چگونگی اعلان آن‌ها را در [فصل بعدی](kotlin-tour-basic-types.md) توضیح می‌دهد.

## تمرین

### چاپ یک جمله با قالب‌های رشته‌ای

کد را کامل کنید تا برنامه `"Mary is 20 years old"` را در خروجی استاندارد چاپ کند:

```kotlin
fun main() {
    val name = "Mary"
    val age = 20
    // Write your code here
}
```

> [!example]- راه‌حل نمونه
> ```kotlin
> fun main() {
>     val name = "Mary"
>     val age = 20
>     println("$name is $age years old")
> }
> ```
